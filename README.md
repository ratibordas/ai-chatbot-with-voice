
# ai-chatbot-with-voice

AI chatbot supporting text messages and files with voiceovers in English and Russian. Powered by **Google Gemini** and React Compiler

---

## Live Demo
🔗 [**Try it here**](https://ratibordas.github.io/ai-chatbot-with-voice/)

---

## Features

- 🎤 **Voiceover Support** — English & Russian speech synthesis for Edge / Chrome  
- 📂 **Files Upload** — Works with PDFs, documents, images, and more  
- 🧠 **Context Management** — Adjustable conversation memory via slider  
- 📊 **Token Tracking** — Real-time token usage display  
- 📱 **Responsive UI** — Built with `radix/ui` for accessibility and style  
- 💾 **Persistent Storage** — Saves chat history in `localStorage`  

---

## 🤖 Supported AI Models

### Google Gemini 2.5 Flash
- **Model ID:** `gemini-2.5-flash`  
- **File Support:** JPEG, PNG, GIF, WebP, PDFs, text files, and more  
- **Max Upload:** 1,000 document pages per file  


📚 [Full Gemini 2.5 Flash Documentation](https://cloud.google.com/vertex-ai/generative-ai/docs/models/gemini/2-5-flash)

## Installation

Install dependencies & and launch:
```bash
npm install && npm run dev
```

The application will be available at `http://localhost:5173`
